# Basic Portfolio Website — HTML, CSS & JavaScript

A responsive beginner portfolio project with comments explaining important concepts.

## Files

- `index.html` — semantic page structure and content
- `css/style.css` — design tokens, box model, Flexbox, Grid, responsive media queries, focus states, hover effects
- `js/script.js` — DOM selection, event listeners, mobile navigation, form validation, template strings, Date, IntersectionObserver

## Run it

1. Extract the ZIP.
2. Keep the folders in the same structure.
3. Open `index.html` in a modern browser.
4. Edit the sample name, biography, skills, project descriptions, and contact details.

No package installation or build step is required.

## Important learning notes

- This is a front-end demo. The contact form validates in the browser but does not send messages.
- The project cards and skill percentages are sample content. Replace them with accurate information.
- For a real portfolio, add your own project links, real contact information, and a backend or form service if you want submissions delivered.
- JavaScript is loaded with `defer`, so the HTML is parsed before the script executes.

## Add your About-section photo

Put your portrait inside `images/` and name it `profile.jpg`. The About section references `images/profile.jpg`. If you use another name or format, change the `src` value in `index.html`. Update the sample biography and quick facts too.
